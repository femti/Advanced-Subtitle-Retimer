# Руководство по установке и запуску

Этот инструмент синхронизирует субтитры (`.srt`) с аудиофайлами (`.mp3`) с помощью утилиты `alass`, предварительно очищая их от лишних символов.

## Требования

1.  **Python 3**
2.  **alass** — инструмент для синхронизации.
    *   **Arch Linux:** `yay -S alass`
    *   **Другие:** Скачайте со [страницы релизов](https://github.com/kaegi/alass/releases) и добавьте в `PATH`.
    *   Проверка: в терминале команда `alass --version` (или просто `alass`) должна работать.

## Установка и запуск

Проект использует автоматический скрипт `run.sh`, который сам создает виртуальное окружение и устанавливает зависимости.

### 1. Подготовка файлов

1.  В корне проекта есть папка **`file_work`**.
2.  Поместите туда ваши файлы:
    *   Аудиофайлы: `.mp3`
    *   Субтитры: `.srt`
3.  Файлы должны совпадать по количеству и сортироваться в правильном порядке (например `01_audio.mp3` и `01_sub.srt`).

### 2. Запуск

Находясь в корневой папке проекта, выполните:

```bash
./run.sh
```

*(Если скрипт не запускается, дайте ему права на исполнение: `chmod +x run.sh`)*

### Что произойдет?

1.  Скрипт создаст виртуальное окружение (если его нет).
2.  Очистит субтитры от спецсимволов и лишних тегов (сохранив промежуточную копию).
3.  Синхронизирует их с аудиофайлами с помощью `alass`.
4.  Готовые файлы будут обновлены в папке `file_work`.
