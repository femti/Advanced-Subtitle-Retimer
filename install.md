# Руководство по установке и запуску

Этот скрипт позволяет синхронизировать файлы субтитров (`.srt` или `.ass`) с аудиофайлами (`.mp3`).

## Требования

Для работы скрипта необходимо установить следующее:

1.  **Python 3** (версии 3.6 или выше).
2.  **alass** — инструмент для синхронизации субтитров.
3.  **pysubs2** — библиотека Python для работы с субтитрами.

## Установка

### 1. Установка Python и зависимостей

Убедитесь, что у вас установлен Python. Затем установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

### 2. Установка alass

Скрипт использует команду `alass` для синхронизации. Вам нужно установить его и убедиться, что он доступен в командной строке (PATH).

*   **Linux (Arch Linux):** `yay -S alass`
*   **Другие системы:**
    *   Скачайте исполняемый файл со страницы релизов: [https://github.com/kaegi/alass/releases](https://github.com/kaegi/alass/releases)
    *   Распакуйте его и поместите в папку, доступную в переменной окружения `PATH` (или укажите полный путь в скрипте, если требуется, но по умолчанию скрипт ищет команду `alass`).

## Как пользоваться

1.  Поместите все ваши аудиофайлы (`.mp3`) и файлы субтитров (`.srt` или `.ass`) в одну папку.
2.  Количество аудиофайлов должно совпадать с количеством файлов субтитров. Скрипт сортирует их по имени и сопоставляет пары.
    *   Пример:
        *   `episode_01.mp3` <-> `subs_01.srt`
        *   `episode_02.mp3` <-> `subs_02.srt`
3.  Запустите скрипт из этой папки:

```bash
python3 /путь/к/скрипту/main.py
```

Или, если вы находитесь в папке проекта:

```bash
python3 main.py
```

*(Примечание: скрипт ищет файлы в текущей рабочей директории, откуда он был запущен).*

4.  Синхронизированные субтитры будут созданы в той же папке (или перезаписаны/созданы новые файлы, в зависимости от логики `alass` и скрипта). В текущей реализации скрипт создает новые файлы с расширением субтитров, добавленным к имени аудиофайла (например, `episode_01.mp3.srt`).
